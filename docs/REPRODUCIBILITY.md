# Reproducibility
Adam LR.001, betas(.9,.999), eps1e-8, weight_decay0, single parameter group; 100epochs, seed2026, no pretraining/AMP/accumulation/early stopping. ReduceLROnPlateau factor.95, patience10 scheduler calls, min_lr1e-6, validation segmentation loss only every10epochs. TUT/Cam drop training last batch; PY retains it. TUT baseline/CSSG and PY checkpoint ties use IoU then lower FP; TUT LBAS/Cam retain earlier on equal F1.
Main loss is positive-weighted BCE on clamped probabilities, positive weight 3*total_train_pixels/positive_train_pixels. LBAS=.5 dynamic-pos-weight BCEWithLogits+.5 batch-global softDice(eps1e-6), lambda=.10, target3x3 morphological gradient. CSSG has independent 64->1 and128->1 score convolutions and trainable sigmoid beta initialized.1; no GAP/Context/Fuse inside CSSG. Model files are copied without mathematical changes. No backbone freezing.
Training checkpoint selection used historical Val search .50:.01:.99. Final V2 audit held checkpoints fixed and searched .05:.01:.99 on Val, not Test. Core nine thresholds: TUT baseline/cssg/lbas .97/.96/.98; Cam .98/.95/.98; PY .98/.96/.98. Main F1 and IoU use pooled pixel counts. Strict loss/checkpoint identity is required for paper numbers. External methods are excluded; the historical PY Crackmer repair used frozen Val threshold .39, not the retired .50 result.
Confirmed efficiency environment: RTX4090, PyTorch2.0.0+cu118, CUDA11.8, FP32 batch1. All historical training environments have not been independently recovered. No released weights, no runtime reproduction, no verified Linux support, Cam split distribution permission pending, TUT source link pending. Dependencies are import-derived, not a tested lockfile.
